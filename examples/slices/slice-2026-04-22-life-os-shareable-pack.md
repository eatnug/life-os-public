# Life OS Shareable Pack

The current goal is to explain [[life-os|Life OS]] without exposing private memory.

The useful shareable version should include the architecture, a small runtime shape, and a few examples that show how slices, entities, and stories work together. A repo with no memory examples would be hard to evaluate, but the full private repo contains material that should not be shared.

Decision:

- Create a small sanitized repo.
- Include selected neutral examples.
- Keep private source memory out of the public package.
- Make the roadmap focus on agent behavior, not note organization.

Open question:

Can an agent become more useful over time by maintaining source memory as slices, linking recurring entities, and building views only when they are useful?

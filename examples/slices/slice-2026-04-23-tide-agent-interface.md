# Tide Agent Interface

[[tide|Tide]] is part of the user's broader interest in agent workflows.

The product direction is not just "run commands in a terminal." The more interesting question is how an interface should help a human stay oriented while multiple agents, tasks, logs, and decisions are moving at once.

This connects to [[life-os|Life OS]] because both projects are about agent behavior over time:

- Tide focuses on operational flow while work is happening.
- Life OS focuses on durable memory and context across conversations.

The common theme is reducing the amount of state the human has to hold manually.
